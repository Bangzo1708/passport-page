The Passport Page of a Country That Isn't There. Your entry is a program that writes one image to /output/entry.png: an invented passport spread — the open passport of the fictional Republic of Zalissia, a landlocked steppe republic between Borovnya and the Tarkhan Khanate, drawn entirely with Pillow: a trilingual data page, entry/exit stamps for two trade trips, a Tarkhan business visa, and the telling paperwork detail that trade is limited to wool and amber only.

## Run it

```sh
python3 main.py
```
